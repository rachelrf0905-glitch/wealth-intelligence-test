# 财富认知力评估 · Wealth Intelligence Assessment

这是一个无需安装依赖、无需服务器的静态测试网站。

## 使用方法

1. 在浏览器里直接打开 `index.html`，即可预览。
2. 将 `index.html` 上传到 GitHub 仓库根目录。
3. 打开仓库 `Settings → Pages`，选择 `Deploy from a branch`、`main`、`/(root)`，保存。
4. 待页面发布后，通过 `https://<你的用户名>.github.io/<仓库名>/` 访问。

## 功能

- 首页六位验证码验证（固定码值不会显示在页面上）
- 10 道经济决策、商业洞察与人际协作情境题
- 5 个能力维度、6 个认知等级、动态人格名称和个性化文字分析
- 再次测试
- 原生 Canvas 导出 PNG 图片，自动排除操作按钮；不需要外部图片或 CDN
- 支持手机和电脑浏览器，无须收集任何个人信息

## 注意事项

- **这只是前端验证码门槛，并非安全认证**。对于公开的 GitHub Pages 网站，具备技术知识的访客仍能通过源代码或浏览器工具绕过验证。真实访问控制需要后端支持。
- 报告属于探索性自测，不预测财富状况或投资结果。
- GitHub Pages 将公开托管仓库文件，请勿在网页中放入敏感密钥。
